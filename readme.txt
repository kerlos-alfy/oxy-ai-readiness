Prepare your WordPress website for AI Search, AI Agents & the Future of the Web.

== Description ==

Oxy AI Readiness audits, validates, generates, and scores the signals AI
crawlers, agents, and assistants use to understand a WordPress site
(robots.txt, llms.txt, structured headers, Markdown negotiation, content
signals, and more).

This plugin is under active development. This readme reflects only the
foundational scaffolding built so far; module-level features are documented
as they ship.
